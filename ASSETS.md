# Assets

The local build uses Minecraft Java 1.21.1 textures, models, fonts, and sounds. These are excluded from the repository, along with music and packaged executables. Screenshots show the application using that local resource pack.

## Included

| Files | Source |
| --- | --- |
| `Assets/Textures/` | Procedural pixel textures |
| `Assets/Audio/` | Synthesized sound effects |
| `Assets/icon.png`, `Assets/chest.ico` | Generated chest icon |
| `Assets/Fonts/Pixel.ttf` | Press Start 2P, under the included [SIL Open Font License](Assets/Fonts/OFL.txt) |

The textures, effects, and icon are generated by `scripts/generate_assets.py`. They do not replace the complete resource pack required by the current renderer.

## Resource pack

The renderer expects resources under `Assets/Vanilla/`. This directory is ignored by Git. A compatible pack with appropriate usage rights is required to run or package the application.
