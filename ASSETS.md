# Asset inventory

The personal build uses Minecraft Java 1.21.1 assets. The entire `Assets/Vanilla/` directory is excluded from Git, including textures, Minecraft fonts, GUI artwork, entity skins, exported block model JSON, effects, weather recordings, and music download manifests. No Minecraft music, client archives, game packages, or personal media are included in this repository.

Included assets:

| Path | Origin |
| --- | --- |
| `Assets/Textures/` | Procedural pixel textures generated by `scripts/generate_assets.py` |
| `Assets/Audio/` | Synthesized WAV effects generated by the same script |
| `Assets/icon.png`, `Assets/chest.ico` | Generated pixel chest icon |
| `Assets/Fonts/Pixel.ttf` | Press Start 2P; SIL Open Font License in `Assets/Fonts/OFL.txt` |

The generated assets are legacy artwork, not a complete replacement for the personal build's Minecraft assets. In particular, the synthetic ambience is not played in the current build.

## Running the renderer

A fresh clone does not contain the complete resource pack required by the renderer. Source references to `res://Assets/Vanilla/` describe the expected paths; they do not grant rights to those resources. A complete, compatible pack with permission for its intended use is needed before running or packaging. No automatic Minecraft asset downloader is provided in the repository.

Do not publish the personal `dist/` folder: it includes the private resource pack. Replacing the resources with a distributable pack and validating it on a clean Windows machine remain future release work.
